TrustLens

Loan Fraud Detection Platform

A containerised platform for automated loan-fraud assessment, built for the Canara Bank SuRaksha Hackathon 2.0: an async FastAPI REST API and React frontend over a 10-stage pipeline from OCR to risk scoring, run with Docker Compose. Long-running work moves into Celery workers with every stage idempotent, so failed jobs retry without duplicate writes, and a transactional outbox commits database changes and Kafka events together. Security policy lives in code — JWT with refresh-token rotation, Argon2 hashing, TOTP MFA, four-role RBAC and startup checks that block production runs with weak secrets — and CI runs pytest, Ruff, Bandit and secret scanning.

CrowdWise

Traffic Deployment Planning Service

A deployed FastAPI service that turns a city event calendar into ranked congestion chokepoints and officer deployment plans, with REST endpoints for prediction, retraining, CSV upload and event ingestion. It deploys to Render from declarative config with a health-check endpoint and secrets kept out of the repository, and a scheduled job re-forecasts as new events arrive. A historical replay of 8,173 Bengaluru Traffic Police events estimates a 23.3% reduction in vehicle-hours of delay.

03

Flimo

Cloud Search Service & Deployment Pipeline

A deployed FastAPI search API backed by a FAISS vector index, with ingestion pipelines pulling data from the TMDB and YouTube APIs. It runs on AWS EC2 behind an Nginx reverse proxy from a multi-stage Docker build; a GitHub Actions pipeline (push → SSH → build → health check) automates releases and cut deployments to 68 seconds, and HTTPS is served through a Cloudflare Tunnel run as an auto-restarting systemd service.
